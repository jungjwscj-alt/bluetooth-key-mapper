# APK 설치 차단 안내

Google Play 프로텍트는 웹브라우저 등에서 직접 다운로드한 Android APK가 민감한 권한인 접근성(Accessibility) 서비스를 요청하면 설치를 차단할 수 있습니다. 이는 실제 악성 여부와 무관하게 보호 정책에 따라 일어날 수 있습니다.

- **Full APK**: 접근성 서비스와 IME를 사용해 상하/좌우 스와이프, 뒤로가기 등 동작 가능. 일부 단말에서 인터넷으로 직접 설치 시 차단될 수 있습니다.
- **Lite APK**: 접근성 서비스를 선언하지 않고 IME 기능만 포함. 앱의 버튼 학습과 현재 입력란에서 제한적인 키 매핑을 시도할 수 있지만, 다른 앱의 스크롤·뒤로가기·전역 매핑은 불가능합니다.
- Lite 버전도 Google Play 프로텍트와 제조사 정책에 따라 설치 차단될 수 있습니다. IME는 입력 데이터를 처리할 수 있으므로 선택 전에 앱 출처를 확인하세요.

보호 기능을 일괄 비활성화하는 것은 권장하지 않습니다. 전체 기능을 안전하게 배포하려면 공식 앱 마켓 심사와 접근성 사용 목적 설명 등을 갖추는 것이 우선입니다.

참고: https://developers.google.com/android/play-protect/warning-dev-guidance
